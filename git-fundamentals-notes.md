What is Git?

Git is a version control system used to track changes in files and source code. It helps developers manage projects efficiently and collaborate with others. Git keeps a history of all modifications made to a project.

What is GitHub?

GitHub is an online platform that hosts Git repositories. It allows developers to store, share, and collaborate on code projects. GitHub also provides features like pull requests and issue tracking.

What is a Branch?

A branch is a separate line of development in Git. It allows developers to work on new features or changes without affecting the main project. Branches can later be merged into the main branch.

What is a Commit?

A commit is a saved snapshot of changes made to a project. Each commit includes a message describing the changes. Commits help track the progress and history of a project.

What is a Pull Request?

A pull request is a request to merge changes from one branch into another. It allows team members to review code before it is added to the main branch. Pull requests improve collaboration and code quality.
